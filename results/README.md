# results/

Benchmark output lands here and is **committed on purpose** — the CSVs and charts are the evidence
that makes this a portfolio, not just code.

- `summary.csv` — one row per run (auto-appended by `bench/benchmark.py`).
- `*_c*.csv` — per-request detail for a single run.
- `charts/` — PNGs from `bench/analyze.py`.

Reference these from each `experiments/*/README.md` so every claim links to a number.
